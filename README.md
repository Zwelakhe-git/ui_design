# Forma — Visual HTML Builder

Forma is a lightweight, browser-based UI builder for creating simple layouts and exporting them as standalone HTML.

## Use the app

Open `index.html` in a modern browser. No installation, build step, or server is required.

## Features

- Add rectangles, circles, and layout containers.
- Arrange top-level elements by dragging them on the canvas; drag a shape over a container to place it inside, or move a container over shapes to collect them.
- Resize selected elements with the canvas handles.
- Shift-click layers or drag over an empty area of the canvas to select multiple elements. Move a multi-selection together or wrap it in a horizontal, vertical, or grid container.
- Edit element names, dimensions, position, fill and border color, border width and style, and corner radius.
- Set shadows, reorder selected layers, and duplicate with Ctrl+D or Ctrl-drag.
- Hover over width, height, or position fields and use the mouse wheel to adjust values; hold Shift to adjust in larger steps.
- Add elements to a selected container and configure flex or grid layout, gap, padding, direction, columns, and overflow behavior.
- Drag an element out of its container to make it a top-level element, or drag a container over sibling elements to collect them.
- Let containers automatically fit their child content.
- Assign optional HTML IDs to individual elements.
- Switch between Desktop, iPhone 16 Pro, Tablet, and custom artboard dimensions.
- Preview the canvas and export a self-contained HTML file or copy its source.
- Save the current design automatically in the browser's local storage.
- Collapse and expand the inspector's Size & Position, Appearance, Layout, and Shadow sections.

The design is stored locally in the browser and is not uploaded.
